# Reverse Proxy Backend (FastAPI)

Example [FastAPI](https://fastapi.tiangolo.com/) backend for testing a reverse proxy. Its endpoints help check redirects, large responses, headers, timeouts and request size limits behind a proxy.

## <a name="dev"></a>Run locally

```bash
# install dependencies
pip3 install -r requirements.txt --break-system-packages

# start the app
python3 main.py
```
