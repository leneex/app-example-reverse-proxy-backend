# Reverse Proxy Backend (FastAPI)

**Backend-приложение** на [FastAPI](https://fastapi.tiangolo.com/) для **тестирования reverse proxy**.

Приложение выступает в роли апстрима: reverse proxy направляет запросы на него, а его эндпоинты позволяют проверить поведение прокси — редиректы, передачу больших ответов, работу с заголовками, таймауты и лимиты на размер тела запроса.

## Эндпоинты

| Метод  | Путь              | Назначение                                                            |
| ------ | ----------------- | --------------------------------------------------------------------- |
| `GET`  | `/`               | Проверка доступности бэкенда                                          |
| `GET`  | `/new`            | Целевой адрес для проверки редиректов на прокси                        |
| `GET`  | `/large-text`     | Большой ответ — проверка буферизации и передачи объёмных тел           |
| `GET`  | `/headers-source` | Отдаёт заголовок `X-Delete-Me` — проверка правил изменения заголовков  |
| `GET`  | `/slow-response`  | Ответ с задержкой (`?delay=` в секундах) — проверка таймаутов прокси   |
| `POST` | `/echo-size`      | Возвращает размер полученного тела — проверка лимитов на размер запроса |

## <a name="dev"></a>Локальный запуск проекта

```bash
# установка зависимостей
pip3 install -r requirements.txt --break-system-packages

# запуск приложения
python3 main.py
```
